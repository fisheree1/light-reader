# 在线轻小说获取：实施记录与验收

更新日期：2026-10-15。目标为日本轻小说已有中文译本，按卷加入现有书架。设计背景及 GitHub 参考见 [设计提案](online-book-discovery-design.md)。

## 已实现的代码

- `/discover` 懒加载页面，书架及侧栏入口；Bilinovel / Linovelib 分别搜索、查看卷册、多卷串行获取、独立结果、失败卷重试、进度和取消。自动搜索受限时，支持打开书源窗口正常寻找作品，再返回主窗口点击“读取书源窗口”；这个动作不会重新提交搜索。
- 桌面独立、可见的来源 WebView：Bilinovel 从 `/search.html`、Linovelib 从首页提交各自实际的搜索表单，兼容当前 `/S6/` 等数字搜索结果入口，只向主应用返回有大小限制的页面快照。通过 DOMContentLoaded 确认正文就绪，不等待广告等全部资源加载；导航优先使用页面自己的链接事件。同源的 `_blank` 作品链接转为在当前隔离窗口打开。远程窗口不授予主窗口的文件、SQL、备份权限；自定义命令再校验调用窗口必须为 `main`。实际弹窗、直接下载及非白名单导航仍被拒绝。
- 搜索、目录、正文解析：兼容 `.volume-chapters` 与桌面 `.volume-list > .volume` 两种卷册模板，以及 `#acontent` / `#TextContent` 正文；保持目录顺序，识别半卷和外传。受限的 `javascript:` 章节使对应卷不可选择，画集及显式日版条目单独禁用。分页校验作品、章节及页码，拒绝重复、跳页及循环；桌面 `.mlfy_page` 的“下一页”若实际指向同作品的另一章，则视为章末。隐藏干扰内容（包括零缩放段落）、脚本、事件、表单等不进入 EPUB。没有 href 的分页从页面 ReadParams 中读取经过路径校验的 next 字段，不执行其中的代码；无法确定下一页时整卷失败。目录中的替代字符标题使用正文页实际标题纠正。
- 封面及插图采用原生 HTTPS 下载，仅接受来源主机及已确认的 `img3.readpai.com`，重定向逐跳校验，DNS 解析后固定公网连接地址。支持 PNG/JPEG/GIF/WebP 类型识别，失败默认终止；用户可明确选择缺图，生成物记录缺图数量。
- 每卷生成标准 EPUB 3 容器、目录、章节、ruby 注音、本地图片及来源页。同一输入生成稳定字节，沿用既有文件 SHA-256 去重。
- `BookImportService.importBytes()` 复用原有校验、解析、暂存、提交、Repository 写入和失败补偿；本地文件选择仍调用同一入口。
- 来源身份保存在已有 `books.metadata_json.origin` 中，字段经过 Zod 校验，与书籍在同一次 Repository 创建时保存；Web 同样保存在现有书籍对象中。删除和备份自然跟随书籍，无新增 SQL 表或迁移。EPUB 的来源页及 `dc:source` 同时记录来源。
- 共享导入沿用当前前端/Rust 一致的 schema 12，本功能不增加数据库版本。

上述来源元数据方案替代初稿的独立 `book_origins` 表：首版每本书只记录一个生成来源，不需要额外关联事务，也不提供跨来源作品合并、版本对比或自动追更。

## 平台与资源边界

生产 Web 静态部署没有原生来源服务，页面明确提示使用桌面端，仍可打开来源网站。Playwright 的自建来源仅在 `import.meta.env.DEV` 且显式设置 `VITE_DISCOVERY_FAKE_SOURCE=true` 时注入，生产构建删除该分支。

Bilinovel 与 Linovelib 作为两个独立身份，兼容各自的目录和正文模板，不假设书号一致。`linovel.net` 是独立的轻之文库原创平台，尚未接入。初版没有自动翻译、登录凭据提取、验证码自动处理、任意 URL 代理、自动绕过受限章节或后台采集。

页面请求串行，相邻读取完成后至少间隔 2 秒；原生单页超时 40 秒，前端 IPC 等待另有 45 秒兜底。图片 DNS 最多 5 秒，整次下载最多 35 秒，连接最多 5 秒，前端等待最多 40 秒。取消立即释放前端等待，原生同时停止对应请求；过期响应与取消按请求 ID 隔离。单页 HTML 限制 2 MiB，单张图片 10 MiB，单卷原始资源及生成文件各限制 64 MiB；最多 500 章、每章 20 页、250 张不同图片。任务只在内存中编排，确认入库时使用现有受控暂存目录；取消已提交步骤不会删除正式书籍。失败重试从该卷开始，暂不支持退出应用后续传。

## 可靠性与访问礼貌（2026-10-15 补充）

- 所有书源请求严格串行并共用一个间隔：页面之间至少 2 秒，图片之间至少 1 秒。
- 不做任何自动重试。HTTP 403 记为访问被拒，429 或限流提示页记为请求过于频繁；两者都会立即停止当前卷，并跳过队列中剩余的卷。即使允许缺图，这类错误也不会被当作“缺一张图”继续。
- 收到限流后 2 分钟内，所有书源请求都在本地直接拒绝，不再访问来源。
- 失败或取消后重试同一卷时，复用本次会话已获取的页面和图片，只请求缺失部分；成功入库后清除缓存，最多保留 2 卷。
- 章节文本中的 XML 非法字符（C0 控制符、U+FFFE/U+FFFF、孤立代理项）在生成 XHTML 前移除。
- 搜索“无结果”只认明确的空结果提示，标题为“搜索结果”的空白页或异常页会报解析错误，而不是显示“未找到作品”。

### M2：译本元数据、简繁与跨站分组

- 每卷识别 `kind`（正篇 / 外传 / 短篇集）、`edition`（文库版、Web 版、新装版等）和 `script`（简体 / 繁体 / 混排，基于卷名及章节标题，至少两个可区分字符且占比 ≥80% 才判定）。
- 译者和翻译类型只从来源**明确声明**的行读取（“译者：…”“翻译方式：人工翻译”等），没有声明时记为“未知”，不根据文风推测。目录页与各章节页的声明合并；人工与机翻并存记为“混合”。
- 以上字段写入 `origin`（Zod 可选字段，旧记录兼容），并写进 EPUB：`dc:language` 为 `zh-Hans` / `zh-Hant`，译者为带 `marc:relators trl` 角色的 `dc:contributor`，来源页列出作者、译者、翻译类型和版本。
- 搜索先用输入原文；**仅当没有结果时**再用另一种字形（简↔繁）重试一次，避免成倍请求。
- 书源下拉新增“全部书源”：依次搜索两站，某站失败时保留另一站结果，并提供只重试该站的按钮；全部失败才报错。结果按规范化标题（转简体、NFKC、去标点空白、小写）分组为**候选**，同组的不同书源条目各自独立查看卷册，页面注明“未合并”，不做任何内容或进度合并。
- 简繁转换使用内置单字对照表 `chinese-script-tables.ts`，由 [OpenCC](https://github.com/BYVoid/OpenCC)（Apache-2.0）字典经 opencc-js 1.0.5（MIT）生成，仅取一对一单字映射，不处理词组级转换；随 `/discover` 懒加载，不进入首屏包。

### M1：验收工具

- `epub-validator.ts` 在入库前检查：`mimetype` 为首个未压缩条目、container → OPF、唯一标识与必需元数据、manifest 文件存在且 id 唯一、spine 引用有效且为 XHTML、导航目录存在且非空、每个 XHTML 按 `application/xhtml+xml` 可解析、站内链接与图片均可解析到 manifest、图片 media-type 与文件头一致；缺封面和未登记文件只作提示。存在错误时**不导入**，并显示“未通过结构校验”。
- 每次获取返回 `AcquisitionReport`：预期/实际章节数、抓取页数、图片总数/嵌入/缺失、每章页数/字数/图片数、疑似过短章节（无图且少于 100 字）、EPUB 大小与校验结果。获取结果中显示摘要，并可“复制验收报告”为 JSON，失败的校验也保留报告。

## 验证记录

自动测试均使用原创文本和自建图片，不把第三方小说正文作为测试夹具。

- Vitest：解析、分页、脚本过滤、注音、图片、确定性 EPUB、共享导入、去重、取消、缺章/缺图和现有备份服务，共 54 项通过，包含浏览器辅助读取、页面就绪、快照去重、IPC 无响应时的取消与超时、实际搜索路径、站内新窗口链接、桌面卷册与正文回归。
- Playwright：搜索到选卷、实际 Web Repository 入库、重复获取、Foliate 目录跳转、本地插图解码、断网重开后的正文，以及无结果与访问拒绝区分，共 2 项通过；第二项同时覆盖切换来源时清除旧错误，以及自动搜索失败后读取当前来源页的恢复路径。
- Cargo：来源路径/主机白名单、图片公网地址限制、快照分片顺序、任务取消、搜索词按字面值注入及跨来源就绪事件拒绝，共 4 项通过；另有隔离于 CI 的真实封面冒烟测试，使用生产 Rust 下载实现读取一张已确认封面，已通过。
- TypeScript/Vite 生产构建与 macOS Tauri debug app 构建通过；最终原生修正后的 Cargo 测试、格式检查及 Rust Clippy 均通过。
- 真实来源原生联调：系统 WebView 已完成 Bilinovel 首页、自动搜索、12 卷目录及首卷获取。修正后的样例 EPUB 含 15 章、24 张本地图片，正文 XHTML 共 345,874 字节，未发现远程或未替换的图片地址；现有 Foliate 阅读器已显示目录、正文及内嵌插图，最终构建重启后可重新打开。初次试验发现的标题替代字符、无 href 分页和零缩放干扰段落已分别修正并添加原创夹具回归。早期验证卷不代表完整内容。初期自动搜索曾出现空白页/超时；分别配置两站入口后，最终 Bilinovel 搜索回归已通过。浏览器辅助读取同样已验证可用。
- Linovelib 原生联调：首页真实表单搜索、作品结果、站内详情页和 12 卷目录回传已通过；首卷显示 15 个可用章节，受限卷与画集按预期禁用。针对它的 `/S6/` 搜索入口、`_blank` 作品链接、桌面卷册与 `#TextContent` 正文差异，已按实际页面结构适配并增加原创夹具回归。尚未重复进行这个独立来源的真实整卷入库验收。

## 尚需分别验收的项目

以下各项的执行步骤和记录模板见 [验收清单](online-book-discovery-acceptance.md)。

1. 扩大两站真实搜索样例，核对简繁标题、多结果及无结果。初期出现的搜索超时和结构差异已定位并修正，请求结束后会返回主窗口展示结果或错误；来源的后续改版仍需要维护适配。
2. 已完成 Bilinovel 一卷的获取及阅读冒烟；Linovelib 真实整卷入库仍待分别验收。后续需对更多作品逐项比对章节、分页、封面和彩插，不能由一个样例推断全部作品完整。断网重开目前由原创夹具的 Playwright 用例验证。
3. 核实来源当前自动访问条件与内容保存范围；403、挑战页或受限章节应停止并显示原因，不将它们保存为正文。
4. 逐平台验证系统 WebView 差异。目前只构建和联调 macOS，Windows/Linux 尚未验收。

`robots.txt` 的先前普通 HTTPS 探测返回 403；本次普通浏览器能访问首页、搜索、目录及短章节，仅证明当前访问路径可用。保留这两个独立事实，不把浏览器成功推断为纯 HTTP、所有卷或所有平台均可获取。

本机保留了早期不完整的调试书籍 `2c7eb307-35b6-40cb-89ff-1410d52ae3ae`，修正版为 `b764a741-cfa7-43bd-bd24-bf1f8e04ffca`。尝试通过现有书籍管理添加调试标签时出现“无法更新书籍信息”提示，标签未保存；没有删除这两本书或修改原有用户书籍。该标签保存问题独立于在线获取，需另行定位。
