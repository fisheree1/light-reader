# 在线轻小说获取：真实卷验收清单

适用于 M1“单卷闭环”的真实来源验收。自动测试只使用原创夹具，真实整卷由维护者在 macOS（及之后的 Windows/Linux）桌面端手动执行。

## 原则

- 只获取你有权阅读的卷，数量以验收需要为限（每个书源 2–3 卷即可），不要批量下载。
- 遇到 403、验证码、“访问过于频繁”等提示时**立即停止**，不要重试或换方式绕过；应用会冷却 2 分钟，记录现象即可。
- 验收报告和截图只在本地或私有 issue 中保留，不要附带小说正文。

## 准备

1. 构建并启动桌面端（`pnpm tauri dev` 或 debug app）。
2. 选择验收样例，尽量覆盖：一卷含彩插的正篇、一卷带“文库版/Web 版”等版本标记、一部繁体作品、一卷外传或短篇集。

## 步骤（每卷重复）

1. 在“在线找轻小说”中搜索作品。分别试一次简体书名和繁体书名，再试一次“全部书源”。
   - [ ] 两种字形都能找到作品
   - [ ] “全部书源”中两站的同名作品出现在同一张卡片中，并注明“未合并”
2. 查看卷册，核对目录页信息。
   - [ ] 卷顺序、卷名与来源一致
   - [ ] 正篇/外传/短篇集、版本、简繁标记与来源一致；无法判断时不显示
   - [ ] 译者与翻译类型：来源声明了则显示，未声明显示“未知”
   - [ ] 受限卷、画集不可选择
3. 获取一卷，等待完成。
   - [ ] 获取结果显示“验收：N/N 章”，两个数字相等，且等于来源目录中该卷的章节数
   - [ ] “结构校验通过”
   - [ ] 图片“嵌入/总数”相等；如果勾选了允许缺图，缺失数与来源实际情况一致
   - [ ] “疑似过短章节”中列出的章节，逐一在来源页核对确实很短（例如插图页、后记）
4. 点击“复制验收报告”，粘贴保存为 `<书源>-<作品ID>-<卷ID>.json`。
5. 打开阅读。
   - [ ] 目录与报告中的章节一致，抽查首章、中间章和末章的首尾段落与来源一致
   - [ ] 跨页章节没有重复或缺页（报告中的 `pages` 与来源分页一致）
   - [ ] 封面、彩插、正文插图都能显示；ruby 注音正常
   - [ ] 来源信息页列出作者、译者、翻译类型、版本和来源链接
6. 断网后关闭并重新打开应用，再打开这本书。
   - [ ] 正文和插图仍可阅读
7. 再次获取同一卷。
   - [ ] 显示“已在书架”，没有产生重复书籍

## 发现问题时

- 结构校验失败：导入已被阻止。附上验收报告 JSON 中的 `validation.errors`（含文件路径和错误代码）。
- 章节数或图片数不一致：附上报告与来源页面的章节列表截图，注明缺失的是哪几章或哪几张图。
- 解析失败或受限：记录错误提示原文和时间；不要反复重试。
