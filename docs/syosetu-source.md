# 小説家になろう 书源

更新日期：2026-10-17。`/discover` 的“なろう（日文原作）”标签页可以搜索「小説家になろう」上作者免费公开的日文网络小说，许多日本轻小说最初就在这里连载，并把它们保存为日文 EPUB。这一功能仅在桌面版可用。

## 范围与礼貌

- 搜索使用官方 API（`api.syosetu.com/novelapi/api`，按评价排序，每页 20 部）。目录页和各话正文是公开的静态页面，不使用隐藏的书源窗口。
- `robots.txt` 只要求 `Crawl-delay: 1`。原生实现把所有请求排成一个队列，相邻请求至少间隔 2 秒；这一限制由 Rust 层强制执行，前端无法绕过。不做任何自动重试：403 视为拒绝，429/503 视为限流，后者触发 2 分钟本地冷却，并停止队列中剩余的卷。
- 只能访问 `api.syosetu.com` 和 `ncode.syosetu.com`，路径限定为 `/{ncode}/`、`/{ncode}/?p=N`、`/{ncode}/{话}/` 三种形式；不跟随重定向，单次响应不超过 3 MiB。R18 站点（`novel18`）不在范围内。
- 插图（挿絵）托管在みてみん上。只接受页面内嵌的固定地址形式 `https://{数字}.mitemin.net/userpageimage/viewimagebig/icode/i{数字}/`；它会重定向到 `img{N}.mitemin.net` 上的图片文件。重定向最多 3 次，每一跳都重新校验主机和图片扩展名。下载与页面请求共用同一个 2 秒间隔的队列，单张图片不超过 10 MiB，每卷最多 250 张。
- 插图被拒绝（403/限流）时，整卷停止。其他原因导致下载失败时，正文中改为显示“［挿絵：取得できませんでした］”，并记入验收报告的缺图数。不符合上述地址形式的图片保留为“［挿絵］”文字。
- 页面上提示：仅供个人阅读。

## 卷的划分

- 目录中的每个“部”（`p-eplist__chapter-title`）作为一卷；没有分部的作品，或超过 100 话的部，每 100 话拆成一卷（例如“第二部（第101–200話）”）。
- 卷 ID 取该卷第一话的编号。作者以后追加话或部时，已有卷的 ID 保持不变，因此“书架中已有”的标记和“检查更新”仍然准确。
- 目录最多读取 30 页（3000 话），超出时页面会提示。短篇作品的正文就在作品页上，作为单独一卷。

## EPUB

- `dc:language` 为 `ja`，来源页不显示“译者/翻译类型”。可选“竖排（縦書き）”：此时 CSS 使用 `vertical-rl`，spine 使用 `page-progression-direction="rtl"`。
- 保留 ruby 注音（`ruby/rt/rp`）和空行，前书、后书分别放在 `.preface`、`.afterword` 中。脚本、图片及其他标签会被移除。
- 写入 EPUB 3 系列（作品名 + 卷序）和 `origin`（`source: syosetu`，`novelId` 为 ncode）。书架会自动按系列分组，系列行的“检查新卷”链接到 `/discover?source=syosetu&novel=…`，在本标签页打开目录。
- 入库前的结构校验和验收报告与轻小说站点共用。
