# 按原名查找中文译本（Bangumi）

更新日期：2026-10-17。`/discover` 的“轻小说网站”标签页顶部有一个“按原名查找中文译本”入口：用日文原名、中文名或简称在 [Bangumi 番组计划](https://bgm.tv) 查找作品，显示其中文译名、别名和官方中文版，然后用这些译名同时搜索两个书源。这一功能仅在桌面版可用（Bangumi API 不提供 CORS）。

## 流程

1. 先调用 `POST /v0/search/subjects`（书籍类），只保留平台为“小说”且非 NSFW 的条目。系列条目排在前面；系列已出现时，去掉其单卷条目（用 NFKC 比较，`!` 与 `！` 视为相同）。只有一个结果时直接展开。
2. 再调用 `GET /v0/subjects/{id}` 读取 infobox：
   - **官方中文版：** 来自 `版本:*` 中语言为简体中文或繁体中文的条目，包括版本名、出版社/出品方、译者、发售日和册数。界面提示通过正规书店购买，不提供任何下载。
   - **中文译名：** 依次取版本名及其别名、`name_cn`、`中文名`、`别名`。只保留含汉字且不含假名的名称，去重后最多 6 个。
3. 点击“用 N 个译名搜索书源”：译名先转成简体去重（书源搜索本身会再尝试另一种字形），最多 3 个；然后依次用每个译名搜索两个书源，合并结果。遇到拒绝或限流时立即停止后续译名；某个书源在所有译名下都失败时才报告。
4. なろう 作品的目录页有“查找中文译本”按钮，会以 `?lookup=作品名` 打开本页并自动查找。

## 访问边界

`src-tauri/src/bangumi.rs` 只允许访问 `https://api.bgm.tv/v0/search/subjects` 和 `/v0/subjects/{1–99999999}` 两个固定端点。请求按 Bangumi 的要求携带可识别的 User-Agent，相邻请求间隔至少 1 秒，同时只处理一个请求，不跟随重定向，响应不超过 2 MiB。

这个功能不新增任何内容抓取站点，书源搜索仍沿用现有的两个站点及其礼貌限制。
